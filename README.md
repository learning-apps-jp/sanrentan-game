# サンレンタン！

端末1台を順番に渡して遊ぶ、2〜6人用のローカルパーティーゲームです。

出題者が6つの選択肢から好みの1位〜3位を決め、他の参加者がその順位を予想します。29問のプリセットと自作お題に対応しています。

## 遊び方

1. 参加者名と周回数を設定します。
2. 出題者に端末を渡し、秘密の順位を選びます。
3. 回答者に順番に端末を渡し、予想を入力します。
4. 全員で答えと得点を確認します。

同点の場合は同点優勝です。自作お題は使用したブラウザーに保存されます。再読み込みすると進行中のゲームはリセットされます。

`index.html` 単体で動作し、外部ライブラリやネット通信は使用しません。
